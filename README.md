# Few Hands — Engineering Studio

> Modern Web Development, Platform Migration Hub & AI Video Production.

## 🚀 Tech Stack
- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript
- **Icons:** [Lucide React](https://lucide.dev/)
- **Hosting Target:** [Vercel](https://vercel.com/) Edge Network

---

## 🧭 Core Funnel Structure
1. **Hero Hub:** Value proposition, social proof (16+ years experience, 50+ projects in US/EU), client showcase.
2. **Platform Migration Hub:** Turnkey migration from legacy CMS & builders (WordPress/WooCommerce, Tilda, Webflow, Bitrix, InSales, legacy PHP) to Next.js.
   - Technology Partnership with [gomvp.dev](https://gomvp.dev/en/migrate).
3. **Bespoke Web Development:** High-converting landing pages, catalogs, and enterprise hubs.
4. **Media & AI Production:** Turnkey AI Video Avatars (9:16 Shorts) & YouTube production.
5. **Interactive Project Estimator:** Dynamic cost & timeline calculator with 1-click lead dispatch to Telegram.
6. **Portfolio Showcase:** Live client websites (Elena Stazhkova, IWD Solutions, MIPT Global, AMT-G, Big Data Realty, Vivasan USA) & video samples.
7. **Direct Lead Capture:** Seamless Telegram, WhatsApp, and email integration.

---

## 🛠 Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 📦 Production Build

```bash
npm run build
npm run start
```

## ☁️ Deployment on Vercel
1. Log in to [vercel.com](https://vercel.com) using your GitHub account (`andreibdr`).
2. Click **Add New...** -> **Project**.
3. Select `fewhands` and click **Deploy**.
4. In **Project Settings** -> **Domains**, bind `fewhands.com`.
